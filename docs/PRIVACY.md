# Privacy and Data Handling

This Skill package contains workflow instructions, templates, and small local helper scripts. It does not include telemetry, tracking code, credentials, user media, personal contact details, or automatic upload code.

The Skill may instruct an AI agent to inspect project files or use media-generation and editing tools. Those actions are performed by the host AI client and its connected tools, not by a hidden service in this package. Follow the host client's data controls and do not send private or copyrighted source assets to external services unless you are authorized to do so.

Before publishing a project archive, remove source media, private paths, credentials, API tokens, personal contact details, and any material that is not licensed for public distribution.
