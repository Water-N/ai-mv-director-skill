# 阶段一：素材调查

执行 AI MV Director 阶段一。

1. 盘点源文件和已有工程。
2. 核验歌名、歌手、专辑、发行年份、版本和封面。
3. 完整检查音频中的倒放、电话音、口白、讲话、合唱、数数、重复口号、呼吸、现场欢呼和其他特殊声音。
4. 核对实际演唱歌词及时间，不猜词。
5. 分析 BPM 是否恒定；恒定时拟合网格，不恒定时建立逐拍地图。
6. 用低音/和弦变化辅助确定小节第一拍。
7. 列出前奏、主歌、副歌、间奏、桥段、尾奏的时间和小节位置。
8. 分析专辑封面的构图、人物造型和可复用视觉母题。
9. 检查仓库中实际存在的模型和脚本。

交付分析报告和待确认事项。不得生成画面。等待确认。
